# 1eso

Aquí hi anirà el material per a l'alumnat de 1r d'ESO. Encara no hi ha res: els recursos
d'aquest curs no seran els mateixos que els de `4eso/`.

Per començar-lo:

1. **Copiar de `4eso/` el que serveixi** i adaptar-ho aquí: els fulls d'estil de `css/`, la
   caixa d'eines o `eines/comprova.py`, per exemple. Una còpia, no un enllaç: si `4eso/`
   canvia, el material de 1r no s'ha de moure.
2. **Escriure els documents d'aquest curs** a `docs/`: el mapa d'adaptació i els criteris de
   disseny.
3. **Per als exàmens DOCX, fer servir el motor comú**, `../comu/examens/nucli.js`. El
   contingut va a `generadors/examens/udN.js` i les dades privades, a
   `generadors/examens-privat.json` (vegeu `../comu/docs/EXAMENS-DOCX.md`).
4. **Quan hi hagi material**, canviar l'`index.html` de l'arrel del repositori per una
   portada que deixi triar el curs, i afegir a `_headers` les línies de memòria cau de
   `/1eso/`.
